Install Steps
1
Make sure you are using Chrome or Edge browser.
Chrome is recommended
2
Tap the ⋮ three-dot menu at the top-right of the browser.
Top right corner
3
Tap Install app or Add to Home screen
4
A dialog will appear. Tap Install to confirm.
5
Done! 🎉 Open Denom's from your Home Screen or App Drawer.
If you don't see "Install app", the browser may have hidden it. Try visiting this page in a fresh Chrome tab or clearing browser cache.
